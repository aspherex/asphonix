## ASPHONIX 0.2.0

SONIX is now **ASPHONIX**. Settings, library cache and saved logins live under the new app id (`dev.asphonix.app`),
so after updating from 0.1 you sign in once more and the library syncs again.

### New
- **German interface.** Settings > Language: System, English or Deutsch, switches without a restart.
- **Windows installer** (per user, no admin rights).
- **Log files** for troubleshooting: `%LOCALAPPDATA%\dev.asphonix.app\logs`, kept for 7 days, never containing
  passwords or tokens. Settings > Diagnostics > Verbose logging adds detail.

### Faster
- **Visualizer switch** in the queue rail header: turns off the row bars and the rail spectrum (Now Playing keeps
  its own). Playing on the Tracks page then costs under a third of the CPU (4.5 % -> 1.3 % of a core on the UI
  thread).
- Position updates repaint only the views that show the position, not the whole window.
- Minimized, the window no longer repaints at all (0.94 % -> 0.31 % of a core while playing).

### Removed
- The Claude / MCP bridge (`asphonix-mcp`). Old settings files with its options still load.

### Accessibility
- Every control reachable with Tab shows a visible focus ring.
- Warning text (red) now has enough contrast in both themes.
- Larger click targets for the "New playlist" buttons in the sidebar.

### Fixed
- The queue rail could briefly show an outdated queue after quick changes.
- Minimizing while lists were still loading could refill them in the background and use memory.

### Under the hood
- Security updates: bundled SQLite 3.54.1, `url` 2.5.9.
- Many new automated tests, including UI tests that replay random timing.
